# Social Media Application

## Description

This is a social media application created for the JavaScript 2 course at Noroff.

The project uses the Noroff API v2 and is built with HTML, CSS, and vanilla JavaScript.

## Features

* Register and login
* View all posts
* View a single post
* Create, edit and delete your own posts
* View posts from other users
* Follow and unfollow users
* Search posts
* View your own profile

## Built With

* HTML
* CSS
* JavaScript
* ES6 Modules
* Noroff API v2

## How to Run the Project

-Open index page
- use the buttons or search bar to navigate
- to see the other persons profile you must click their username after opening one of their post. there you can also follow or unfollow them
- to create post you must click the create button, then to edit or delete click you post either from the feed or from your profile page
